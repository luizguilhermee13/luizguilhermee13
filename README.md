# 🚀 Projetos em Destaque

## 🛞 Gerenciador de Pneus

Sistema web para **controle, gestão e rastreabilidade de pneus de frotas**, sendo atualmente meu projeto de maior escopo.

O projeto surgiu a partir da experiência adquirida em atividades relacionadas à gestão de pneus, estoque e operação de frota, permitindo transformar situações observadas no ambiente profissional em regras de negócio para uma aplicação web.

Entre os módulos desenvolvidos estão:

- Controle e cadastro de pneus
- Controle de estoque
- Movimentações
- Recapagem
- Sucateamento
- Indicadores operacionais
- Controle de sulco e vida útil dos pneus
- Integração entre front-end, API e banco de dados

### Tecnologias utilizadas

`HTML` `CSS` `JavaScript` `Tailwind CSS` `Chart.js`

`Node.js` `Express` `PostgreSQL` `Supabase`

🌐 **Aplicação:**  
https://gerenciador-pneus.web.app

📂 **Repositório:**  
https://github.com/luizguilhermee13/Gerenciador_Pneus

> 🟡 Projeto em desenvolvimento ativo. Atualmente estou trabalhando na integração e evolução do backend, API e banco de dados.

## 🚲 Bikcraft

Site completo e responsivo desenvolvido durante o curso **HTML e CSS para Iniciantes da Origamid**.

O projeto simula uma empresa de bicicletas elétricas e foi desenvolvido com foco na construção de páginas completas, organização de CSS e criação de interfaces responsivas.

## 🔴 Pokédex

Aplicação desenvolvida para praticar **JavaScript e consumo de APIs**, utilizando dados fornecidos pela PokéAPI.
